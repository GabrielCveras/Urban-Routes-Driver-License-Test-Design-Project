# Urban-Routes-Driver-License-Test-Design-Project

Projeto de Quality Assurance (QA) realizado durante minha formação em testes de software, com foco no design de testes para o formulário “Adicionar carteira de motorista” do Urban Routes.

O objetivo do projeto foi analisar os requisitos do formulário e preparar a documentação de teste. Nesta etapa, o escopo era o design dos testes: não era necessário executar os testes na aplicação.

## 🎯 Objetivos do Projeto

Analisar os requisitos do formulário “Adicionar carteira de motorista”.

Definir classes de equivalência positivas e negativas para os campos “Nome”, “Sobrenome” e “Data de nascimento”.

Identificar valores-limite aplicáveis a esses campos.

Escolher dados de teste para verificar as classes e os limites definidos.

Escrever casos de teste para o campo “Nome” com base nos valores selecionados.

## 📋 Design de Testes

Para os três campos indicados nos requisitos, a documentação foi organizada para contemplar:

Classes de equivalência válidas e inválidas.

Valores-limite aplicáveis às regras de cada campo.

Dados de teste para cenários positivos e negativos.

Com base nos valores escolhidos, foram preparados casos de teste para o campo “Nome”.

Os casos descrevem as condições e os dados necessários para verificar o comportamento esperado do campo conforme os requisitos.

## 🧪 Técnicas de Teste


✅ Design de Testes Baseado em Requisitos

✅ Particionamento de Classes de Equivalência

✅ Análise de Valores-Limite

✅ Seleção de Dados de Teste

✅ Preparação de Cenários Positivos e Negativos

✅ Escrita Estruturada de Casos de Teste
